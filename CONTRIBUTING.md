# Contributing

Thanks for checking out this repo! This is a personal learning repository, so I'm not actively seeking contributions. 
But I've outlined some guidelines below in case you'd like to engage.

---

## About This Repo

This is a solo learning project where I document my progress, experiments and notes as I explore. 
The code here is often a work-in-progress and may not follow production best practices.

---

## Opening Issues

Issues are welcome for:

- **Corrections** — spotted a bug, typo, or factual error? Please let me know!
- **Suggestions** — have a resource, approach, or concept worth exploring? I'd love to hear it.
- **Questions** — curious about something I've done? Feel free to ask.

Please keep issues focused and constructive.

---

## Pull Requests

I'm generally **not accepting pull requests** for this repo, since the goal is for me to learn by doing. 
That said, if you spot something clearly broken or incorrect, feel free to open a PR with a brief explanation, and I'll consider it.

---

## Code Style

There's no enforced style guide here, but I try to keep things:

- Readable over clever
- Documented where something non-obvious is happening
- Consistent within each project or module

---

## Code of Conduct

Be kind and respectful. This is a learning space.
